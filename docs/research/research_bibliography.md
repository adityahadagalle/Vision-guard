## 4. Security Advisories & Format Standards

23. **PyTorch Deserialization Security Advisory (CVE-2025-32434)**
    - **Organization:** PyTorch Foundation / Meta AI
    - **Year:** 2025
    - **Identifiers:** CVE-2025-32434, GHSA-2025-32434
    - **Subject:** Object graph deserialization bypass in `torch.load` with `weights_only=True` in PyTorch versions prior to 2.5.1 / 2.6.0.
    - **Reference:** [https://github.com/pytorch/pytorch/security/advisories](https://github.com/pytorch/pytorch/security/advisories)

24. **PyTorch C++ weights_only Unpickler Memory Corruption Advisory (CVE-2026-24747)**
    - **Organization:** PyTorch Foundation
    - **Year:** 2026
    - **Identifiers:** CVE-2026-24747, GHSA-63cw-57p8-fm3p
    - **Subject:** `weights_only` unpickler memory corruption and potential arbitrary code execution via integer overflow during tensor buffer calculation in PyTorch versions $\le 2.9.1$ (patched in $\ge 2.10.0$).
    - **Reference:** [https://github.com/pytorch/pytorch/security/advisories/GHSA-63cw-57p8-fm3p](https://github.com/pytorch/pytorch/security/advisories/GHSA-63cw-57p8-fm3p)

25. **PyTorch Arbitrary File Read Advisory (GHSA-v32g-mr63-3j83)**
    - **Organization:** GitHub Security Advisories / PyTorch
    - **Year:** 2026 (Published: November 10, 2026)
    - **Identifiers:** GHSA-v32g-mr63-3j83 (No CVE currently assigned)
    - **Subject:** Potential arbitrary file read during `torch.load(weights_only=True)`.
    - **Reported Affected Versions:** $\ge 2.14.0$; Reported patched in $2.15.0$.
    - **Reference:** [https://github.com/pytorch/pytorch/security/advisories/GHSA-v32g-mr63-3j83](https://github.com/pytorch/pytorch/security/advisories/GHSA-v32g-mr63-3j83)
    - **Advisory Tracking:** Newly published AI-assisted advisory with no package listed; status is tracked and subject to verification with future official updates.

26. **RFC 8785: JSON Canonicalization Scheme (JCS)**
    - **Organization:** IETF
